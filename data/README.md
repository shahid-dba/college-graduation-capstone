# Data directory

`processed/college_graduation_analysis.csv` is the analysis-ready, institution-level dataset generated by the executed notebook. It contains 1,669 colleges and the variables used in the reported statistical and predictive analyses.

The large raw College Scorecard archive and expanded CSV are not committed to Git. Their official source, filenames, sizes, and SHA-256 checksums are documented in `raw/source_manifest.json`. Run `python scripts/download_scorecard_data.py` or execute the notebook from the repository root to recreate the local raw files.

The data are public institution-level records. No student-level or personally identifiable information is included.
